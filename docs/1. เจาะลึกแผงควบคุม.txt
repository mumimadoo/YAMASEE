 1. เจาะลึกแผงควบคุม 📋 รายละเอียด (รายละเอียดข้อมูลสื่อ)

  กล่องแสดงผล 📋 รายละเอียด ทางด้านขวาบนของหน้าแดชบอร์ด ได้รับการดึงข้อมูลและมีตรรกะเบื้องหลังดังนี้ครับ:

  📂 ชื่อ (Name)
   * การแสดงผลในหน้าเว็บ (#detail-name):
       * กรณีวิเคราะห์ YouTube / TikTok: แสดงผลเป็น URL ลิงก์ของ YouTube หรือ TikTok จริง ที่นำเข้ามาวิเคราะห์ (เช่น
         https://www.youtube.com/watch?v=...)
       * กรณีอัปโหลดไฟล์ในเครื่อง (Local File): จะแสดงผลเป็นชื่อของไฟล์วิดีโอนั้น ๆ หลังจากถูกคัดลอกหรือแปลงสภาพเข้าสู่โฟลเดอร์สำหรับบริการเว็บ
         (เช่น media_1719912345.mp4)
   * การทำงานเบื้องหลัง:
       * ระบบจะใช้โมดูล VideoEngine ตรวจสอบและดึงข้อมูล Unique Video ID จาก URL หากเป็นลิงก์ออนไลน์
       * หากเป็นไฟล์อัปโหลด ระบบจะนำเนื้อหาไฟล์จริงมาเข้ารหัสแฮชแบบ SHA-256 เพื่อเป็นรหัสอ้างอิงเนื้อหาที่ไม่ซ้ำกัน
         ทำให้ระบบสามารถจดจำชื่อและประวัติของเนื้อหานี้ได้ แม้ว่าจะเปลี่ยนชื่อไฟล์ก็ตาม

  💾 ขนาดไฟล์ (File Size)
   * การแสดงผลในหน้าเว็บ (#detail-size): แสดงผลคำว่า "วิเคราะห์จากระบบคลาวด์" เป็นค่าเริ่มต้น (Fallback)
   * การทำงานเบื้องหลัง:
       * ในขณะที่ผู้ใช้อัปโหลดไฟล์ ระบบจะมีการส่งพารามิเตอร์ file_size_bytes ไปที่ Backend เพื่อประเมินจำนวน Token
         และราคาก่อนเริ่มประมวลผลจริง
       * เนื่องจากข้อมูลประวัติเดิมที่ถูกบันทึกในรูปของไฟล์ JSON (ในโฟลเดอร์ analysis_history) ไม่ได้มีการจัดเก็บตัวแปร file_size_label
         เจาะจงลงไป ระบบหลังบ้านจึงประเมินและประมวลผลผ่านโมเดลคลาวด์โดยสมบูรณ์
         ทำให้หน้าบ้านสับเปลี่ยนข้อความแสดงผลแบบเรียบง่ายเป็นแนวทางการทำงานแบบออนไลน์ว่า "วิเคราะห์จากระบบคลาวด์"

  ⏱️ เวลาทั้งหมดในการวิเคราะห์ (Total Analysis Time)
   * การแสดงผลในหน้าเว็บ (#detail-analysis-time):
       * แสดงผลว่า "โหลดด่วนจากแคชประวัติ (Instant Cached)"
   * การทำงานเบื้องหลัง:
       * กรณีดึงจากประวัติเก่า (Cache Hit - เร็วที่สุดใน 1 วินาที): เมื่อป้อน URL เดิม หรือ อัปโหลดไฟล์ที่มีแฮช SHA-256
         ตรงกับประวัติเก่าในโฟลเดอร์ analysis_history ระบบจะไม่ประมวลผลใหม่เพื่อเซฟ Token และเวลา
         แต่จะสกัดไฟล์ประวัติเก่าขึ้นหน้าจอแสดงผลให้แบบทันที (Instant Cached)
       * กรณีรันงานใหม่ (Fresh Analysis): ในโค้ด Backend มีการเริ่มจับเวลาด้วย pipeline_start_time = time.time() ทันทีที่เริ่มทำงาน
         แต่เนื่องจากระบบหลังบ้านไม่ได้บันทึกพารามิเตอร์ของระยะเวลาการคำนวณจริงลงในประวัติผลลัพธ์ JSON
         ตัวแปรหน้าบ้านจึงแสดงผลลัพธ์หลักเป็นเชิงแจ้งผู้ใช้งานว่า "โหลดด่วนจากแคชประวัติ (Instant Cached)"
         เมื่อข้อมูลประมวลผลเสร็จสิ้นและบันทึกลงสู่แคชถาวรเรียบร้อยแล้ว

  2. ขบวนการทำงานเบื้องหลังของระบบ (System Processing Pipeline)

  เมื่อท่านกดยืนยันการวิเคราะห์ ระบบจะมีขั้นตอนการทำงาน (Pipeline) ประสานกันแบบสถาปัตยกรรม Modular ดังต่อไปนี้ครับ:

   1. การเช็กประวัติเก่าล่วงหน้า (Pre-check Cache & Token Estimation):
       * ตรวจสอบว่าลิงก์หรือไฟล์ดังกล่าวเคยวิเคราะห์หรือยัง ถ้าเคยแล้วจะดึงขึ้นมาทันที
       * ถ้ายังไม่เคย ระบบจะดึงความยาวสื่อผ่านเครื่องมือ yt-dlp หรือคำนวณจากขนาดไฟล์ เพื่อนำมาหาความหนาแน่นและประเมินปริมาณ Token
         พร้อมคำนวณราคาเป็นเงินบาทให้เรากดยอมรับก่อน
   2. การดึงสัญญาณและดาวน์โหลด (Video Retrieval Phase):
       * ดาวน์โหลดวิดีโอจากออนไลน์ผ่านมาตรฐานที่ยืดหยุ่นด้วย yt-dlp (หลบหลีกด่าน PO Token ของ YouTube และหลีกเลี่ยงปัญหาของ TikTok)
         บันทึกเป็นไฟล์ต้นฉบับ .mp4 ลงในโฟลเดอร์ cache
   3. การสกัดและซ่อมแซมเสียง (Audio Extraction & Fallback Layer):
       * ใช้โปรแกรม ffmpeg เพื่อถอดแยกเสียงจากไฟล์วิดีโอต้นฉบับออกมาเป็นไฟล์ .mp3
       * หากไฟล์วิดีโอไม่มีสัญญาณเสียงหรือเสียหาย ระบบจะมีโครงข่ายสำรองเพื่อทำการซ่อมแซมและสร้างเสียงเทียม (Silent Audio Layer)
         เพื่อป้องกันระบบหยุดทำงาน
   4. การปรับเรียงสตรีมวิดีโอเพื่อหน้าเว็บ (Remux & Timebase Sync):
       * ใช้วิธีรันคำสั่ง ffmpeg แบบแก้ปัญหาวิดีโอจอดำ และซิงค์จังหวะแกนเวลาภาพกับคำพูดให้ตรงกันแบบถาวร (Timebase Sync)
         พร้อมสตรีมผ่านโมเดลหน้าบ้านได้ทันที
   5. การถอดเสียงเป็นข้อความตามพิกัดเวลา (Dynamic Timestamping STT):
       * ใช้เอนจิน TranscriptEngine (ซึ่งควบคุมการประมวลผลผ่าน Generative AI จาก Google Gemini) ค่อย ๆ
         คัดกรองและเกลาภาษาไทยที่สะกดเพี้ยนให้กลายเป็นประโยคที่สละสลวยและระบุตำแหน่งวินาทีของการพูดแต่ละประโยคอย่างชัดเจน ออกมาเป็น
         Timeline
   6. การวิเคราะห์ยุทธศาสตร์เชิงลึก 8 โมดูล (AI Strategic Analysis):
       * นำ Timeline ข้อความทั้งหมดส่งให้ AIAnalysisEngine ซึ่งเป็นโมเดล AI (ใช้ Gemini API ตระกูล Flash) ทำการสรุปความ สกัดคำสำคัญ
         วิเคราะห์อารมณ์ความรู้สึกในแต่ละช่วงเวลา สรุปภาพรวมจิตวิทยา และแยกบทเรียนและบทย่อย (Chapters)
