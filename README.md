# YAMASEE - ระบบวิเคราะห์สื่อวิดีโอและเสียงเชิงลึก
# YAMASEE - Advanced Video and Audio Analysis Tool

YAMASEE เป็นระบบวิเคราะห์สื่อวิดีโอและเสียงระดับโปรดักชันที่ผสมผสานระบบถอดความคำพูด (Speech-to-Text) ผ่าน Faster-Whisper และการวิเคราะห์เชิงลึกด้วยปัญญาประดิษฐ์ระดับแนวหน้า (Google Gemini AI) ระบบมาพร้อมกับสิทธิ์ผู้ใช้งานที่รัดกุม (RBAC) และระบบเก็บบันทึกประวัติการทำงานความปลอดภัยสูง (Audit Trails)

---

## ฟังก์ชันการทำงานหลัก (Core Features)

1. **ถอดความและวิเคราะห์สื่อจากแหล่งต่าง ๆ**:
   - ลิงก์วิดีโอ YouTube
   - ลิงก์วิดีโอ TikTok
   - ไฟล์วิดีโอ MP4 อัปโหลดตรงจากเครื่อง (Local Upload)
2. **AI Analysis & Insight Generation**: ประมวลผลถอดความ แยกฉาก วิเคราะห์อารมณ์ และสร้างสรุปด้วยโมเดล Gemini
3. **ระบบผู้ใช้งานและแผงควบคุมแอดมิน**: จัดการบัญชีผู้ใช้ บล็อก/แบน แสดงข้อมูลภาพรวมเซิร์ฟเวอร์ และประวัติการทำงานความปลอดภัยสูง
4. **ความน่าเชื่อถือระดับโปรดักชัน**: ระบบสืบค้นข้อมูลสื่อบันทึกเก็บเฉพาะที่ (isolated media paths) ประมวลผล resumable jobs คิวงาน และแคชไฟล์เสียงอัตโนมัติ

---

## ความต้องการของระบบ (Prerequisites)

- **Python**: เวอร์ชัน 3.10 ขึ้นไป
- **Database**: PostgreSQL เวอร์ชัน 18.4+
- **System Tools**:
  - `ffmpeg` และ `ffprobe` (ต้องถูกติดตั้งบนเครื่องและตั้งค่าอยู่ใน System PATH)
  - `yt-dlp` (เครื่องมือภายนอกสำหรับดาวน์โหลดสื่อเสียง/วิดีโอ)

## ขั้นตอนการติดตั้งและการรันระบบ (Setup & Running)

### 1. การเตรียมสภาพแวดล้อม (Environment Setup)
ติดตั้งไลบรารีและดีเพนเดนซีที่กำหนด:
```bash
pip install -r requirements.txt
```

### 2. การกำหนดค่าระบบ (Configuration)
สร้างไฟล์กำหนดค่า `.env` โดยคัดลอกรูปแบบจากต้นแบบ:
```bash
cp .env.example .env
```
เปิดไฟล์ `.env` และกรอกข้อมูลการเชื่อมต่อจริง:
- ตั้งค่า `DATABASE_URL` ให้ชี้ไปยังฐานข้อมูล PostgreSQL ของคุณ
- สร้าง `APP_SECRET_KEY` ที่ปลอดภัย (ความยาวขั้นต่ำ 64 ตัวอักษร)
- ระบุ `GEMINI_API_KEY` เพื่อเชื่อมต่อ AI Engine

> [!WARNING]
> **ระบบความปลอดภัยที่สำคัญ**: ห้ามนำไฟล์ `.env` หรือไฟล์ที่มีความลับจริง (.dump, .db) คอมมิตขึ้นระบบ Git/GitHub เด็ดขาด!

### 3. รันการย้ายโครงสร้างฐานข้อมูล (Database Migrations)
ใช้ Alembic ในการสร้างตารางและดัชนีต่าง ๆ บน PostgreSQL:
```bash
python -m alembic upgrade head
```

### 4. รันระบบเซิร์ฟเวอร์ (Starting Server)
- **การรันในสภาพแวดล้อมการพัฒนา (Development)**:
  ```bash
  python -m uvicorn main:app --host 127.0.0.1 --port 8000
  ```
- **การรันสำหรับใช้งานจริง (Production Entrypoint)**:
  ```bash
  python -m uvicorn main:app --host 0.0.0.0 --port 8000
  ```

## โครงสร้างโฟลเดอร์สำหรับ Runtime Data

ระบบเก็บไฟล์และแคชของงานประมวลผลวิดีโอไว้แยกเฉพาะเพื่อป้องกันข้อมูลชนกัน:
- `data/media/`: เก็บวิดีโอแยกตามประเภท (youtube, tiktok, local)
- `data/cache/`: เก็บส่วนย่อยเสียงและไฟล์ VAD คิวงานประมวลผล resumable
- `backups/`: เก็บไฟล์ประวัติการสำรองฐานข้อมูล
